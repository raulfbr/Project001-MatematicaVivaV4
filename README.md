| Guardião | Virtude | Frase-Assinatura |

| 🦊 **Celeste** (Raposa) | Curiosidade | *"Sente esse cheiro? É aventura."* |

A criança não pensa "estou fazendo conta." Ela pensa **"estou ajudando a Celeste!"**
