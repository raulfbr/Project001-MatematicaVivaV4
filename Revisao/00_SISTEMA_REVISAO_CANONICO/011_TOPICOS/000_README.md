# Topicos da Revisao

Esta pasta contem um arquivo por secao da licao canonica.

Ela define o contrato-alvo de cada topico.
Ela nao substitui o guia central de ativacao.

## Como usar esta pasta
1. ativar a sessao pelo `023_GUIA_CENTRAL_ATIVACAO_REVISAO_TOPICO_A_TOPICO.md`;
2. usar este diretorio para auditar a licao topico por topico;
3. preencher a matriz `001-012` sem pular nenhum bloco;
4. tratar divergencia entre contrato e HTML como finding real de revisao;
5. reauditar topicos tocados e seus vizinhos apos cada patch relevante.

## O que cada arquivo por topico precisa entregar
1. contrato tecnico;
2. contrato narrativo;
3. contrato pedagogico;
4. anti-patterns;
5. `PASS estrutural`;
6. `BLOCK estrutural`;
7. ambiguidades resolvidas;
8. checklist de revisao;
9. prompt operacional para IA.

## Regras desta pasta
1. os 12 topicos devem sempre ser auditados;
2. `topicos relevantes` so vale para transversais adicionais, nao para esta pasta;
3. contrato por topico nao deve reexplicar sozinho a ativacao inteira, porque isso mora no `023`;
4. quando houver duvida entre secoes adjacentes, consultar tambem `014_DELIBERACAO_MODELO_001_003.md`.
