# INDEX - PROMOCAO CANONICA DE FEEDBACK DE MAES REAIS

## 1) Missao deste index
Este arquivo mostra:
1. quais casos ja entraram;
2. quais ja viraram sintese;
3. quais podem virar regra sistemica;
4. quais ainda devem ficar apenas como memoria local.

---

## 2) Estados oficiais
### `LOCAL`
O aprendizado fica no caso e nao sobe.

### `EM SINTESIS`
O caso ja gerou padrao transversal, mas ainda nao virou `CANDIDATO A TRANSVERSAL`.

### `CANDIDATO A TRANSVERSAL`
O aprendizado pode subir para uma transversal operacional futura.

### `CANDIDATO A NORTH STAR`
O aprendizado toca principio duravel de identidade, tom ou empatia.

### `CANONIZADO`
O aprendizado ja subiu para arquivo canonico.

## 4) Gate de promocao
1. `LOCAL -> EM SINTESIS` quando o caso ensina algo para mais de uma licao;
2. `EM SINTESIS -> CANDIDATO A TRANSVERSAL` quando o padrao vira heuristica acionavel;
3. `CANDIDATO A TRANSVERSAL -> CANDIDATO A NORTH STAR` quando o aprendizado toca identidade, tom ou criterio duravel;
4. `CANDIDATO A NORTH STAR -> CANONIZADO` apenas apos confirmacao suficiente em mais de um caso ou em uma rodada forte de sintese.

---

## 5) Regras de leitura
1. este index nao substitui os dossies dos casos;
2. este index nao guarda feedback bruto;
3. este index existe para mostrar maturidade de promocao.
