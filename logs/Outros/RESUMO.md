### O Veredito: Estrutura Modular V7
O Template V7 é um arquivo YAML **rigidamente estruturado** mas **semanticamente rico**.

1.  **Metadados Rastreáveis:** ID, Ciclo, Referência TGTB (para garantir cobertura curricular).
2.  **Separação Ator/Fala:** Não usamos strings longas com "Melquior: Olá". Usamos objetos: `{ator: melquior, fala: "Olá", tom: acolhedor}`. Isso permite ao HTML renderizar o avatar correto automaticamente.
3.  **Acting Cues Isolados:** Instruções de palco (`[Aponte para o céu]`) ficam em campo separado ou sintaxe markdown específica, para diferenciar da fala lida em voz alta.

## 10. A PIPELINE DE GERAÇÃO (YAML → Python → HTML/PDF)
O fluxo de trabalho oficial para criar lições agora é:

1.  **A Criação:** Humano (ou IA) escreve a lição no arquivo `curriculo/01_SEMENTESV6/MV-S-XXX.yaml` seguindo o `_TEMPLATE_V7.yaml`.
2.  **A Validação:** O arquivo YAML é lido. Se faltar a seção "Narramos Juntos", o validador grita (Veto CM).
3.  **O Build:** Um script Python (`build_lesson.py`) lê o YAML e injeta os dados no template HTML (`template_licao.html`).
    *   *Mágica:* Ele converte automaticamente `ator: melquior` -> `<img src="melquior.png" class="avatar">`.
4.  **O Resultado:** Um arquivo HTML único, responsivo, pronto para o celular da mãe (Abra e Faça).
